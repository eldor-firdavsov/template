# Client-mode

Barbershop Client Booking WebApp & Barber Portal integrated with Supabase and Vercel.

- **Client App**: 4-step psychological booking flow (Services, Barber, Time slots, Confirmation & Receipt).
- **Barber Portal**: Barber schedule management, client tracking, real-time booking updates, and statistics.
- **Design System**: iOS Liquid Glass & HIG principles, 60-30-10 color hierarchy, 8pt responsive grid.
